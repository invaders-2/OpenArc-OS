# OpenArc OS 整体设计语言 1.0（草案）

> 版本：1.0 草案 · 2026-10-09
> 性质：**待用户确认的设计决定稿**。确认后取代 `DESIGN_SYSTEM.md` 0.2 中与本文冲突的条目，并据此修订 `src/design-system/tokens.css`。
> 关系：`DESIGN_SYSTEM.md`（色彩、材质、可访问性底线）与 `MOTION_SYSTEM.md`（动效）继续有效；本文在它们之上补齐三件以前没有的东西：
> 1. 对标 DX OS 的**完整界面清单**（壳层 + 全部应用），每个界面落在哪种页面原型上；
> 2. **页面原型**（五种），新应用只能从中选，不再一页一个布局；
> 3. 现有规范、token 和已实现界面之间的**冲突裁决**。
>
> 对标原则：**功能面和信息结构对齐 DX OS，外观一律用 OpenArc 自己的语言**。不复制 DX OS 的配色、图标、文案、版式细节。

## 1. 设计立场（一句话版）

**黑白灰的磨砂玻璃桌面，内容清楚、外壳退后，状态说真话。**

- 层次靠明度差、留白、阴影和玻璃，不靠颜色和描边（沿用 0.2）。
- 每个区域只有一个主操作，主操作是近黑 / 近白实心块。
- 彩色只出现在三处：失败红、成功绿、警告琥珀（各自配图标 + 文字），以及用户自己的内容（照片、视频、画布）。
- 动效解释"从哪来、到哪去"，不制造进度感（见 `MOTION_SYSTEM.md`）。
- 文案中文白话；AI 状态如实显示"在等模型 / 在等设备 / 在验证"，不写"智能处理中"。

## 3. 基础值（Token）裁决

### 3.1 颜色与材质

**10-15 已改为 macOS 27 中性色口径**（纯中性灰、无冷色偏；深色用炭灰而非纯黑；内容区始终不透明，玻璃只留在窗口外壳、侧栏与浮层）：

| 角色 | 浅色 | 深色 |
|---|---|---|
| 文字 labelColor | #262626（黑 85%） | #DFDFDF（白 85%） |
| 次要文字 | #6E6E6E | #989898 |
| 桌面基底 / 主题色壁纸 | #ECECEC / #E8E8E8 | #141414 |
| 窗口外壳玻璃 | rgb(246) · 78% | rgb(42) · 78% |
| 内容区 controlBackground | #FFFFFF（不透明） | #1E1E1E（不透明） |
| 强调（中性单色） | #262626 | #DFDFDF |
| 窗口阴影（活动） | 0.5px 外缘 14% + 18/50 投影 20% | 0.5px 黑缘 + 0.5px 内白缘 14% + 22/60 投影 60% |

其余沿用 `DESIGN_SYSTEM.md` §3、§4（中性灰阶单色、四层玻璃 M0–M3）。另补三条：

1. **用户内容不去色**：照片、视频、画布节点里的用户素材保持原色；外壳、控件、图表一律灰阶。
2. **选中态** = `--sunken` 底 + 文字 500 字重 + 左侧 2px 实心标记（列表）或底部 2px 标记（标签页），不用颜色。
3. **数据图表默认序列**：5 级灰阶（`--text` 100% / 72% / 52% / 34% / 20%），超过 5 个系列改用分面而不是加颜色。

### 3.2 字阶（D2，取代 0.2 §5 的表与 tokens 现值）

| Token | 字号 / 行高 | 字重 | 用途 | 现值 → 新值 |
|---|---|---|---|---|
| `--fs-display` | 28 / 34 | 500 | 锁屏日期下标题、欢迎页主标题 | 27 → 28 |
| `--fs-title` | 20 / 28 | 500 | 应用页面主标题（每页最多一个） | 21 → 20 |
| `--fs-headline` *新增* | 15 / 22 | 500 | 区域标题、卡片标题、对话框标题 | 新增（替代 heading 14） |
| `--fs-body` | 14 / 22 | 400 | 正文、表单、列表主行 | 不变 |
| `--fs-secondary` | 13 / 20 | 400 | 按钮、导航、侧栏、次级说明、窗口标题 | 不变 |
| `--fs-caption` | 12 / 18 | 400 | 时间、元信息、表头、日志 | 不变 |
| `--fs-micro` | 11 / 14 | 400 | 徽标、Dock 名称提示、计数 | 不变 |

- `--fs-heading`（14）与 `--fs-eyebrow`（10）**废弃**：14 的标题和正文同大，失去层级；10 号中文不可读。
- 页面标题不再用 26 / 27：桌面应用窗口里 20 已足够，DX OS 同类页面也在这个量级。
- 字重只有 400 / 500，`--fw-bold` 保持 500（与 0.2 一致）。
- 锁屏大时钟 `--fs-clock` 不变。

### 3.4 焦点与输入（D3）

- 输入框、按钮、卡片：**鼠标点击后不出现焦点环、外阴影、上浮或放大**；输入框获得焦点时只把底色从 `--sunken` 提亮一级（深色 +4% 白）。
- 键盘导航（`:focus-visible`）：2px `--focus` 外环 + 2px 间隔，所有可交互元素都有。
- 输入框边界：1px `--line`（控件可识别性要求），校验失败时边界和说明文字用失败红并带图标。

## 4. 页面原型（新应用只能从这五种里选）

所有原型共用：**窗口外壳沿用现有实现（已定 10-09）**——`src-vue/shell/WindowLayer.vue` 的标题栏、红黄绿、圆角、阴影、拖动与最小化动效均不改；原型只规定窗口内部的布局。M1 窗口外壳、M0 内容区、24px 页面内边距。

### A · 侧栏详情（Settings 型）
适用：系统设置、组织治理、MCP 中心、模型与服务商、ComfyUI、外部应用入口、图片声明。

```
┌ 标题栏 ──────────────────────────────────────────┐
│ 侧栏 200   │ 页面标题 20                [主操作] │
│ ─ 分组名12 │ 一句话说明 13 次级色                 │
│  导航项 13 │ ┌ 分组卡片（M0 抬起，无描边）─────┐ │
│  导航项    │ │ 行：标签 14 ······ 值 / 控件     │ │
│ ─ 分组名   │ │ 行：标签 + 说明 12 ··· 开关      │ │
│  导航项    │ └──────────────────────────────────┘ │
└──────────────────────────────────────────────────┘
```
- 侧栏顶部是搜索框（DX OS 设置也有"搜索设置"）。
- 内容区最大宽度 720，居左；设置行用"标签左、控件右"的表单行，行间 1px 分隔线只在卡片内部出现。
- 危险操作单独成卡放最下面，按钮是普通次级按钮 + 红色文字，不做红底。
- 列表 + 详情的变体（MCP 中心、组织治理用户页）：侧栏变为 240 宽的条目列表，每项两行（名称 + 状态）。

### B · 集合浏览（Files 型）
适用：访达、资源库、回收站、相册、音乐、应用市场、Skill 中心、短剧项目列表、项目。

```
┌ 标题栏（含返回 / 前进、视图切换、搜索）──────────────┐
│ 侧栏 240 │ 工具条：标题 15 · 计数 12 · 排序 · [新建] │ 详情 320（可收起）│
│ 分类     │ 网格（卡片 12 圆角，缩略图 + 两行文字）     │ 预览 / 属性       │
│ 收藏     │ 或 列表（40 行高，表头 12）                 │                   │
└──────────────────────────────────────────────────────┘
```
- 宽 ≥ 1200 显示三栏；800–1199 详情栏改抽屉；更窄侧栏也收为抽屉。
- 空状态：线性插图 48px + 一句说明 + 一个主操作，不写营销文案。
- 应用市场 / Skill 中心的"卡片"统一一个组件：图标 48、名称 15、一句说明 13、状态（未安装 / 安装中 / 可用 / 有更新 / 已停用 / 失败）。

### C · 会话（Conversation 型）
适用：对话、项目 Agent、助理浮层的展开态。

```
┌ 标题栏 ────────────────────────────────────────────────┐
│ 会话列表 280 │ 会话标题 15 · 目标设备 · 模型          │ 任务侧栏 320 │
│ 搜索         │ 消息流（最大宽 720 居中）              │ 当前任务     │
│ 今天 / 更早  │  用户消息：右对齐，--sunken 底，12 圆角 │ 步骤 / 产物  │
│              │  助手消息：左对齐，无底色，正文 14      │ 审批 / 停止  │
│              │  任务卡：步骤、工具、等待原因、产物     │              │
│              │ ┌ 输入框（附件 · 能力 · 模型 · 发送）┐ │              │
└────────────────────────────────────────────────────────┘
```
- 助手回复不加气泡底色，长文更好读；用户消息有底色以区分。
- 任务卡是一等公民：状态 11 种严格按 `MOTION_SYSTEM.md` §7，成功只在验证通过后出现。
- 需要审批的工具调用以内联卡片出现在消息流里，同时在右侧任务栏置顶。
- 不展示模型思维链，只展示结构化步骤摘要。

### D · 工作区（Editor 型）
适用：AI Studio 画布、视频剪辑、短剧工坊、文稿、浏览器、开发者工作台、相册编辑模式。

```
┌ 标题栏（文档名 · 已保存/已修改 · 分享 · [导出]）──────────┐
│ 工具条 40（M2 浮起，居中或左上悬浮）                      │
│ 左面板 240（图层/素材） │ 画布 / 编辑区（M0，满铺）│ 右面板 280（属性）│
│                         │                           │                   │
│ 底部：时间线 / 状态栏（视频剪辑等需要时）                  │
└──────────────────────────────────────────────────────────┘
```
- 编辑区不加玻璃，内容最清楚；面板和工具条用 M2 浮起。
- 面板都可收起，快捷键统一：`⌘\` 左面板、`⌘⌥\` 右面板。
- 画布节点、连线端口、节点工具条沿用现有 AI Studio 的交互，不重新设计。

### E · 概览（Dashboard 型）
适用：欢迎、自动化概览、日历、天气、系统信息、磁盘空间。

```
┌ 标题栏 ──────────────────────────────────────┐
│ 页面标题 20 · 说明 13             [主操作]   │
│ 指标行：3–4 个统计卡（数字 28 等宽 + 标签 12）│
│ 主区：列表 / 日历网格 / 图表（灰阶）          │
└──────────────────────────────────────────────┘
```
- 统计卡只放真实数据，没有数据时显示"—"和原因，不用假数字。
- 自动化列表每行：名称、触发条件、下次运行、状态（运行正常 / 需要处理 / 等待首次运行 / 已停用）。

### 5.1 布局与层序

### 5.2 应用图标（D1，已定 10-09：全部采用 Apple 样式）

- 全部应用使用与 macOS 原生应用外观一致的图标，来源为开源 **WhiteSur icon theme**（GPL-3.0），不再使用从 macOS 提取的原图。
- 文件、来源对照与许可证：`public/icons/ICONS-SOURCE.md`、`public/icons/LICENSE-WhiteSur.txt`。
- 现有文件名保持不变（apps / safari / finder / folder / freeform / settings / shortcuts / spotlight / trash / trash-full），代码无需改动；另备 12 枚给新应用：messages、app-store、calendar、weather、music、photos、text-editor、terminal、clock、contacts、sharing、video。
- 缺口：无边记（AI Studio）、快捷指令（Skill / MCP）、Siri 在 WhiteSur 中没有对应，分别用「画笔」「⌘」代替；`siri.png` 暂保留原图，仅作 AI 圆球的静态帧，发布前需替换。
- 已知风险（用户已知悉）：这些图标复刻了 Apple 的图标外观，开源许可不覆盖 Apple 的权利；正式发布前请法务确认。

### 5.3 助理浮层（D4）

- 唤起：顶栏 AI 圆球、快捷键 `⌥ Space`、桌面"助理"小组件。
- 形态：屏幕上方 1/3 处的 M2 浮层，宽 640，只有输入框 + 最近 3 条结果；执行任务时向下展开任务卡。
- "在对话中打开"把当前会话移交给对话应用，不复制数据。
- 圆球动效沿用现有 SiriBlob / WebGL 程序化两级方案，**颜色改为中性灰阶光感**（现在偏彩色）。

### 5.4 桌面小组件（D5）

- 尺寸：小 152×152、中 320×152；M2 材质，12 圆角，内边距 16。
- 首版：日期（农历 + 当日日程数）、天气、进行中的任务（最多 3 条，点开对话应用）。
- 右键：移除、调整尺寸；小组件不放主操作按钮。
